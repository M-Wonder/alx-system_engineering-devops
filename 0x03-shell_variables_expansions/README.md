# 0x03. Shell, init files, variables and expansions
This project contains shell scripts demonstrating various shell concepts including aliases, variables, expansions, and arithmetic operations.

## Files Description:
- 0-alias: Creates an alias
- 1-hello_you: Prints hello with current user
- 2-path: Adds /action to PATH
- 3-paths: Counts directories in PATH
- 4-global_variables: Lists environment variables
- 5-local_variables: Lists all variables and functions
- 6-create_local_variable: Creates a local variable
- 7-create_global_variable: Creates a global variable
- 8-true_knowledge: Performs addition with environment variable
- 9-divide_and_rule: Performs division
- 10-love_exponent_breath: Performs exponentiation
- 11-binary_to_decimal: Converts binary to decimal
- 12-combinations: Prints all two-letter combinations except 'oo'
- 13-print_float: Prints number with 2 decimal places
- 100-decimal_to_hexadecimal: Converts decimal to hexadecimal
- 101-rot13: Encodes/decodes with ROT13
- 102-odd: Prints every other line
- 103-water_and_stir: Adds numbers in custom bases
